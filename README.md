
# Simon Says Memory Game 🎮

A fun and interactive **Simon Says Memory Game** built using **HTML, CSS, and JavaScript**.

##  Features

- Random color sequence generation
- Level-based gameplay
- User input validation
- Game-over detection
- Score and level tracking
- Visual button flash effects
- Responsive design

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling

##  How to Play

1. Press any key to start the game.
2. Watch the color sequence carefully.
3. Click the buttons in the same order.
4. Each successful round increases the level.
5. If you click the wrong button, the game is over.
